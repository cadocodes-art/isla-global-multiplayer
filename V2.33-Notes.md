# ISLA V2.33

Each new map visit gets a fresh random Iscoin layout, for accounts and guests. Every main map now targets 240 coins, including Play Place; approved custom maps also target 240 where safe space permits.

- No road/off-road quotas. Keeps 1- and 5-Iscoin rarity and rare 10-Iscoin placements.
- The same visit keeps its layout when opening the garage, pausing, starting to drive or retrying a network request. Leaving and re-entering, including a full page reload, starts a new visit.
- Accounts get personal server-generated layouts, so players in a global room do not share the same coins. Guest layouts are generated locally.
- Collected slots retain their personal three-minute cooldown after a reshuffle. A newly entered map can therefore show fewer than 240 available coins until recent pickups respawn.
- Server position/value checks, map approval checks and existing car, vault and leaderboard features remain.

## Validation

- All 249 automated tests passed, including map placement, account and guest visits, personal cooldowns, server restarts and existing gameplay regressions.
- All five main maps produced 240 safely spaced coins for both tested visit seeds, with fresh positions between visits. Server terrain placement matches the game surface within 2.5 cm.
- Production build, Cloudflare Worker dry-run and offline export passed. The Worker dry-run is a local packaging check, not a deployment.
- The 23-file patch was applied to a clean V2.32 checkout; all 130 manifest files and their generated destinations passed SHA-256 checks. Its rebuilt world data exactly matches the tested build.
- No new physical iPad/Safari playtest was performed for this release.
