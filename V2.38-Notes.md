# ISLA V2.38

- Online map cards and the map detail/stats page now display Plays. The stats page shows the total beside likes and comments, including zero plays and formatted large counts. Every new driving visit counts, including immediate repeat visits. Requests retried within the same visit count once. Popularity, trending and milestone notifications use play totals. Existing recorded visits are kept.

- Mount Inferno, Inferno Vent and Project 13 are deferred. The original five main maps remain.
- The game opens without an extra Start button. Project 10 loops in the vault, starts from the vault-entry click, and stops on exit. The vault includes mute and blocked-playback retry controls.
- Bowling rolls curve gently left or right, chosen once per roll and shared by the server in global rooms. Reduced pin scatter and more sensitive aim make strikes less automatic. The lighter ball remains.
- Offline Owner Controls support multiple car unlocks and upgrade-level grants. Existing balances, unlocks, equipped levels, password verifier and dated History are preserved.
- Nearest-land recovery avoids steep custom-map banks that immediately roll a car back into water.
- All V2.37 changes remain, including evenly spread Costa Metro people, transparent house windows and the StickCar landing reward adjustment.

The existing Mount inferno vault passcode remains valid. It is independent of the deferred map.

The online ZIP is a cumulative update for the complete V2.33 or later repository. The offline TXT is a complete standalone game, with Project 10 embedded and no external downloads.
