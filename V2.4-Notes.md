# ISLA V2.4

Mount Inferno adds one main map with two connected layers. The surface follows
the supplied plan: Galapo Village Ruins, Hally Hill, a dried Riptide Valley,
Inferno Lake and South Pond. The volcano erased the former settlement; no NPCs
or traffic inhabit it. Crater descent loads Inferno Vent and its own minimap.

The Vent has 70% of the surface's width and depth, a central pillar 10 meters
above lava, six car-sized cave approaches, interconnected tunnels, bridges and
suspended platforms. A confirmed teleport returns to the surface. Both layers
support 32-player rooms and 240 personal coins per visit.

Bowling now chooses one small left/right curve per roll, with varied strength.
The room server owns it; snapshots preserve it for every player and late joiner.
Reduced pin transfer and stronger off-center aiming make strikes less automatic
while retaining the lighter bowling ball and possible strikes/spares.

Project 13 loops through the main menu, Map Maker menu, Search and Leaderboard.
Project 10 loops in the unlocked vault. The Start gate unlocks audio before the
game loading screen. One persistent audio element survives menu navigation;
each song resumes its position after a track change. Gameplay and the editor
pause the soundtrack. Both full original recordings are credited to Cado Codes.

Offline Owner Controls add bulk car unlocks and upgrade-level grants. Authentication,
existing levels, equipped levels, balances, the save namespace and dated history
are preserved. Map Maker practice still gives no Aura or Iscoins.

The standalone offline TXT contains all scripts, styles and both full songs.
It is larger than text-document limits; import it directly into an HTML viewer.
The repository's offline build command now produces this complete edition.

A regression check also caught steep custom-map water-recovery banks that could
cause repeated sinking; recovery now selects nearby stable dry ground.

Builds and automated checks cover the changes. Browser checks covered Start and
menu controls. The preview browser lacked WebGL, so 3D rendering needs a device
playtest. No GitHub push or Cloudflare deployment was performed.
